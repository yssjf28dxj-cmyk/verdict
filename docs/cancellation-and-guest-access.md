# Отмена вызова и гостевой доступ

В карточке ожидающего дебата создателю доступна кнопка отмены с подтверждением.
Она вызывает существующий cancelDebateChallenge; прямого удаления клиентом нет.
Сервер проверяет создателя и waiting в транзакции. Если соперник уже принят,
отмена отклоняется. Чужой гость отменить вызов не может.

Перед выходом из анонимного аккаунта профиль показывает предупреждение.
Обычное закрытие приложения не вызывает signOut и не меняет гостевой аккаунт.
Повторный signOut/signInAnonymously может создать новый UID; новый гость
не получает прав старого участника. Это предупреждение не является механизмом
восстановления аккаунта. Привязка гостя к постоянному способу входа — отдельная
будущая задача; перенос роли на произвольный новый UID не добавлялся.

Добавлены строки диалогов для всех семи существующих локализаций.
Проверки: целевой flutter analyze — без замечаний; три реальных вызова
cancelDebateChallenge через эмулятор — успешно (ожидающий владелец, чужой
гость, бой после старта). Требуется проверка диалогов и обновления на устройстве.
Новая сборка staging profile имеет versionCode 4002 (build-number 2002 + смещение ARM64 2000); устанавливать поверх
прежней подписанной тестовой сборки без удаления приложения и без signOut.
Изменений Firebase для этой функции не требуется.
